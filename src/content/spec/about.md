# 关于这个网站

你好，我是 **Doulor**。

这是我的一个个人博客。

这里没有特别明确的主题，也没有打算把它做成一个很“专业”的网站。平时想到什么、遇到什么、折腾了什么，有觉得值得留下来的东西，我就会记下来。

可能是一篇写给自己的日记，一些没头没尾的碎碎念，也可能是一次旅行、一张照片、一首歌，或者某个突然让我感兴趣的东西。

当然，也会有一些技术方面的内容。

比如最近折腾了什么项目，踩到了什么坑，解决了什么问题，或者把某些自己觉得以后可能还会用到的东西整理下来。它们不一定写得很系统，但至少是我确实做过、想过、记过的东西。

所以这里大概会比较杂。

有时候我自己都不知道下一篇会写什么。

## 为什么会做这个网站

其实也没什么特别的理由。

只是觉得很多事情如果不记下来，过一段时间就会慢慢忘掉。

有些当时觉得很重要的事情，过几年可能连具体发生过什么都想不起来了；但偶尔翻到以前留下来的文字、照片，还是会记得那时候的感觉。

所以我想留一个地方，把这些东西慢慢存下来。

不一定是为了给别人看，也不一定非要写得多好。

只是以后回过头来的时候，还能看看以前的自己。

## 关于我

我叫 **Doulor**。

现在还在上学，也还在慢慢摸索自己以后想做什么。

最近在学 C 语言，也会折腾电脑、服务器、一些奇奇怪怪的项目。除此之外，我也喜欢拍照、听歌、记录一些生活里的东西。

兴趣可能经常会变，不过没关系。

想到什么就去试试，喜欢什么就多留一会儿。

大概就是这样。
